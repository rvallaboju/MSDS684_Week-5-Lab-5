# MSDS684 Week 5 Lab 5 Documentation

## Overview
This repository contains the Jupyter Notebook for the Week 5 Lab in the MSDS684 course. The notebook includes various data analysis exercises and is designed to help students better understand the course material.

## Setup Process
To set up the environment and run the notebook, follow the steps below:

### Prerequisites
Ensure you have the following software installed:
- Python 3.x
- Jupyter Notebook

### Installation Steps
1. **Clone the Repository**  
   Clone this repository to your local machine using the following command:  
   ```bash  
   git clone https://github.com/rvallaboju/MSDS684_Week-5-Lab-5.git  
   cd MSDS684_Week-5-Lab-5  
   ```  

2. **Create a Virtual Environment**  
   It is recommended to create a virtual environment for this project:  
   ```bash  
   python -m venv venv  
   source venv/bin/activate  # On Windows use `venv\Scripts\activate`  
   ```  

3. **Install Required Libraries**  
   Install the required libraries using pip:  
   ```bash  
   pip install -r requirements.txt  
   ```  

4. **Run the Jupyter Notebook**  
   Start the Jupyter Notebook server using the command:  
   ```bash  
   jupyter notebook  
   ```  
   Then open the `Week5_Lab5.ipynb` file in your browser.

## Requirements
Make sure to have the following libraries listed in `requirements.txt`:  
- pandas  
- numpy  
- matplotlib  
- seaborn  
- scikit-learn
